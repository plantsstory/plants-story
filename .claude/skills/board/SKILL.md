# 常設ボード会議の手順

1. `BOARD.md` と `docs/board/` の最新会議録を読む（前回の決定・未完了タスクを把握）。
2. 議題を決める。ユーザーの指示があればそれを議題に、なければ BOARD.md の「次回の議題」を使う。
3. 4 つの専門エージェントを **同時に** Agent ツールで起動する（`subagent_type` にエージェント名。定義ファイルが未ロードなら `general-purpose` に `.claude/agents/<name>.md` を読ませて同じ役割を演じさせる）:
   - `monetization-lead`（収益）
   - `taxonomy-editor`（分類・定義）
   - `content-strategist`（集客・コンテンツ）
   - `design-director`（デザイン・UX）
   各エージェントには議題・現状・BOARD.md の要約・実データの取り方（`wireframe/js/app-core.js` の anon key で Supabase REST を curl）を渡す。
4. 4 者の報告を `product-owner` に渡し、決定事項・却下・オーナー依頼・BOARD.md 差分を得る。
5. `docs/board/YYYY-MM-DD.md` に会議録（各報告の要約 + 決定）を保存し、`BOARD.md` を差分どおり更新する。
6. 決定のうち Claude Code が実装できるものは **その場で実装に着手**する（デザイン変更はプレビュー確認を挟む）。
7. ユーザーへの最終報告は「決定事項」「今すぐ着手したもの」「オーナーにしかできない作業（手順つき）」の3部構成にする。

## ルール
- 目標は月1万円の売上。すべての提言に金額か根拠を求める。
- 由来情報の正確性は商品価値。正確性を下げる施策は却下。
- 記憶事項（品種名に種小名必須・不明種に推測名を書かない・由来にサイズ情報を書かない・見た目変更は本番前に確認）を守る。
