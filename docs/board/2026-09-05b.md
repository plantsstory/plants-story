## 2. 衝突6点の裁定

### 2-1. お気に入り（monetization・design「棚として復活」 vs content「登録 ≥50人まで削除維持」）
**裁定: 「棚」として T28 と同時に実装（ログイン不要の localStorage 版）。**
理由: content の反対理由は「ログイン要求が離脱要因」と「本当に欲しいのは所有株リスト」の2点で、design の設計（localStorage、ログイン不要、☆なし）はその両方を満たす。monetization は金額を出した唯一の案（+750円/月の仮説、ログイン率の GA 計測で検証可能）。T28 の印刷 dialog を複数品種対応にする作業と重なるので、別セッションに分けるより同時のほうが安い（+3h）。可逆（1コミットで休止、テーブルは既存）。content の条件「登録 ≥50人」は**撤退判定**に転用する（11月末に保存者 <10人 かつ 会員転換 0 で休止）。

### 2-2. 共有 Facebook / LINE（content「いま復活」 vs monetization・design「削除維持」）
**裁定: Facebook のみ復活（PC 専用・`navigator.share` 非対応環境のみ）。LINE は削除維持。全チャネルに `channel` を付け、90日で 5% 未満は撤去。**
理由: LINE への1対1送信は日本で最多（content）だが、それはモバイルで起き `navigator.share` の OS シートで既に届く。PC で LINE の Web 共有を使う人は稀（monetization・design）。一方 Facebook グループは告知の第3チャネルで、その層は PC 閲覧が多い。告知先に共有ボタンを置かないのは計画と矛盾する。コストは1行なので、計測を付けて実測で決めるのが最も安い。「X · Facebook · URLコピー」の mono 1行はデザイン方針に反しない。

### 2-3. Amazon（monetization「出典書籍限定・12月以降条件付き」 vs content・design「削除維持」）
**裁定: いまは削除維持。12月レビューで「出典書籍限定・条件付き」として再判定。いま着手するのはリンク無しの書誌欄（T38）だけ。**
理由: 3名とも「道具の Amazon は不要」で一致。monetization の追加論点は「洋書の出典を本そのものに繋げる」という資料館として自然な形であり、由来の正確性を下げない。ただし 180日3件の失敗コスト（閉鎖）を避けるには楽天・Yahoo! の実測クリックが先。書誌欄はアフィリの有無に関係なく価値があるので先に置く。

### 2-4. トップの実生区画（content「≥20件・≥5人で台帳部品として復活」 vs design「削除維持 + `.neq` 修正」 vs monetization「`/seedlings/` 索引」）
**裁定: トップ区画は削除維持。`.neq('type','seedling')` を即修正。条件到達（公開実生 ≥20件 かつ 投稿者 ≥5人）で `/seedlings/` 索引ページを作る。**
理由: 決定と実装の食い違い（design 発見）を直せば「人が投稿している」気配は新着記録で出る。条件到達後にトップへ区画を戻すと定義文直下が二重表示になる（monetization）。索引ページは台帳部品の流用で 0.5セッション、5件無料と会員導線を置ける唯一の場所になる。content の条件（≥20件・≥5人）と台帳部品・3列の設計はそのまま採用し、置き場所だけ索引ページにする。

### 2-5. ローンチ日程（content 10/3 vs monetization「決済稼働前に本告知しない」 vs taxonomy「C15 検証済が間に合わなければ告知しない」）
**裁定: 2段階。ソフトローンチ（クローズド）は 9/21 から決済に関係なく開始。本告知は「必須ゲート全達成の翌土曜 20:00」で、目標 10/3、上限 10/24。決済稼働と原種の検証済 100% は必須ゲートに入れる。ただし上限 10/24 に決済だけが未達なら、決済なしで告知する。**
理由: 来訪ピークは一度しか来ず、その時に「会員になる」が準備中だと初月現金（会員5人 × 1,850円 ≈ 9,250円）と継続 2,500円/月が消える（monetization）。検証印ゼロで「正確」と言えば後で撤回になる（taxonomy）。どちらも「品質を決済より先に」というオーナー方針と矛盾しない（品質タスクを先に終え、決済が動いてから告知する）。一方、Stripe と PAY.JP の両方が長引いて告知が11月に入ると、12月末の会員12人（累計来訪 ≈2,500人が必要）が数学的に届かなくなるので上限を置く。Stripe が 10/3 までに判定なしなら T30（500/5,000 への改訂）を先に実施し PAY.JP を申請する（審査中に法務ページを触らない原則は「240/2,500 と 500/5,000 の混在を避ける」ためのもので、両事業者に同じページを見せる状態にすれば目的は満たす）。

### 2-6. オーナーへの確認事項（4名で20件超 vs 「確認質問は最小限」）
**裁定: 8件に絞る（§6）。残りは既定回答で進め、BOARD §3 の既定回答リストに記録する。**
既定で進めるもの（質問しない）: 棚の概念（ボード決定）／ 告知の順序（ボード決定）／ splendidum は W.Bull ex Rodigas (1884) に改める／ 個体区分ラベル 6択／ Mr Chandra は Chandra に、Space Hijau は breeder 表示のまま注記「ナーセリー」／ 'Mystique A88'(109) と 'Galaxy'(110) は現状維持（Hybrid）で本文に「オリジナル個体は存在する／流通は F1」を明記（'King of Spades' 則との整合はオーナーが異論を出したときだけ Clone + tag line に変更）／ 出典書籍の手持ちは無いものとして書誌は公開情報から／ 楽天アフィリ ID 連携は §7-9 のまま。
