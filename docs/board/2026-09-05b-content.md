## 0. 前提: 日本のアロイド界隈で実際に使われている手段

告知計画と再判定の両方の土台。WebSearch と界隈の慣行から。

| 手段 | 使われ方 | 当サイトへの含意 |
|---|---|---|
| **Instagram** | 写真の主戦場。株の記録・交配の経過・販売告知。ハッシュタグ `#アンスリウム` `#anthurium` `#原種アンスリウム` `#アロイド` `#実生`。保存は「Instagram の保存」で完結する | 由来ページは**ストーリーズのリンクスタンプ**か**プロフィールのリンク**でしか貼れない。つまり「URLコピー」が最重要導線。フィード投稿に URL を貼っても飛べない |
| **X** | 界隈の雑談・議論・引用RT。「〇〇の由来って結局なに」型の会話が起きる場所。スレッド形式の解説が伸びる | 告知の第一波はここ。品種ページの X 共有ボタンは正しい |
| **Facebook グループ** | 40代以上のコレクターと海外ブリーダーの情報源。アンスリウムジャパン（anthurium-japan.com）自身が「Facebook グループ・フォーラム・海外ブログから情報収集」と明記。海外は Anthurium 系グループが複数 | 由来の**一次情報の持ち主**がいる場所。PC 利用率が高く、PC の共有ボタンが意味を持つ唯一の層 |
| **LINE** | 個人間の売買連絡・株の相談・グループ。オープンチャット「シロウト園芸」は 1日200件超の投稿、アロイド好きが多い（leafylife101.com/3645） | 「この由来ページ見て」は**LINE で1対1に送られる**のが日本では最多。モバイルは OS 共有シートで LINE に届くが、PC 閲覧者には共有手段が無い |
| **YouTube** | 栽培家チャンネル。由来を語る動画もあるが出典は薄い | 出典 Tier C。集客チャネルとしては「概要欄にリンク」を依頼できる程度 |
| **メルカリ / ヤフオク / BASE / STORES** | 流通の実体。ミッシェル・ザラ・RVDP・ドラヤキは検索上位がヤフオク・STORES。**メルカリは商品説明の外部 URL を禁止**、ヤフオク・BASE・STORES は説明文に URL を置ける | 出品者が「由来はこちら」と当サイトを貼る導線は、ヤフオク・BASE・STORES の出品者と専門店に限られる。メルカリは「名前で検索して当サイトが1位」でしか取れない＝SEO |
| ブログ | アンスリウムジャパン（用語表・育て方・交配記録）、シロウト園芸（交配の成長記録）、koleoblog（交配ガイド） | 育て方・交配手順は彼らが強い。**「誰が・いつ・どこで名付けたか」を出典つきで書いた日本語ページは無い**（前回確認済）。競合ではなく相互参照先 |
| 植物イベント | 秋（10〜11月）に全国で即売会。アロイド枝も出る | 標本ラベル（T28）に QR を入れて株に挿せば、イベント会場が配布点になる |

**告知が一度しかできない界隈**であることが最大の制約: 本気のコレクターは国内で数百人規模、口コミが速い。「見に行ったら空っぽだった」が最初の印象になると二度目は来ない。

## 3. ローンチ計画（どこで・何を・どの順で・いつ）

原則: ①オーナー個人の名義で、栽培家として話す（「運営です」より「作った人」） ②各所のルールに従う（オープンチャットの宣伝規約、FB グループの投稿規約は事前に読む） ③告知は「サイトができました」ではなく「**〇〇の由来を出典つきで調べたら、こうだった**」という**中身の話**にして、リンクは末尾 ④週末夜（土日 20〜22時）に出す ⑤最初の1週間は返信に全部返す。

### 第0週 9/6〜9/20: 準備（ゲート消化）
- Claude Code: T23〜T26、§1 実装（FB/LINE 復活・og-image 刷新・共有文）、T29 を **9/27 まで**に前倒し（今日の一葉 OGP + シェア文コピー + 投稿完了画面のコピペ文）。
- オーナー: シード投稿5件（9/12）、写真（9/21）、§5 の確認事項に回答、告知先アカウントの棚卸し。

### 第1週 9/21〜9/27: ソフトローンチ（クローズド）
- **どこ**: オーナー自身の Instagram ストーリーズ（24時間で消える・親しいフォロワーのみでも可）と、知人ブリーダー2名への LINE/DM。
- **何を**: 「由来を調べる図鑑を作った。まず見て、間違いと足りない名前を教えて」。相手の株の由来ページ URL を1本添える。
- **狙い**: 誤りの洗い出し、投稿導線の実地テスト（知人1名に実際に1件投稿してもらう）、G9〜G11 の最終確認。**ここで見つかった問題は公開前に直す**。
- 指標: 指摘件数（多いほど良い）、知人の投稿1件成立。

### 第2週 9/28〜10/4: 公開ローンチ
- **10/3（土）20:00 X** — スレッド5投稿（下書き §3-A）。1投稿目は中身（'Michelle' の作出者と交配式）、最後にサイト。
- **10/3（土）20:30 Instagram** — カルーセル5枚（下書き §3-B）: 1枚目 今日の一葉の OGP 画像、2〜4枚目 由来3件（記載者・年・産地を mono で）、5枚目 定義文 + 「プロフィールのリンクから」。同時にストーリーズにリンクスタンプ。プロフィールのリンクをサイトに。
- **10/4（日）** — LINE オープンチャット「シロウト園芸」（規約確認のうえ。宣伝禁止なら「質問に答える形」でしか貼らない）。投稿は短く（§3-C）。
