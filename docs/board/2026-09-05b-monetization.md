## 1. 論点 (a) お気に入りは会員の登録導線・特典として価値があるか

**特典としては不採用、登録導線としては形を変えて採用。**

- 特典（有料）にしない理由: 現行の特典は「実在する4つ」に絞った（BOARD §2）。お気に入りを会員限定にすると「無料で使えたものを隠した」と受け取られ、閲覧無料の約束と齟齬が出る。500円の価値を上げない。
- 登録導線として弱い理由: ☆ブックマークは 31〜60件の図鑑ではブラウザのブックマークと同じ。ログインする理由にならない。
- **形を変えると効く理由**: 会員特典②「標本ラベル印刷（全収録品種）」は、実際には「自分が持っている株のラベルを刷りたい」需要。持っている株を選んでおく場所＝所有株リストが無いと、毎回1品種ずつ印刷ダイアログを開くことになる。所有株リスト → 「リストの株をまとめて印刷（A4 8枚）」が、無料ログイン → 会員の最短経路になる。
  - 非会員ログイン: リスト保存は無料、印刷は自分の投稿分のみ（決済稼働後、BOARD §5 の決定どおり）。リストの他の株を印刷しようとした瞬間が**会員ペイウォールの第2の入口**（第1は実生6件目）。
  - コレクターの行動に合う: 株ごとの管理番号・ラベルは既に紙やテプラでやっている人が多い。「図鑑の記録と同じ表記のラベル」は Instagram に写り込む（露出）。
- 実装: `favorites` テーブルをそのまま使う（`user_id, cultivar_name`）。UI は詳細ページの操作行に「所有株に加える」1語、マイページに「所有株（n）」一覧 + 「まとめて印刷」。旧ナビ項目・☆アイコン・専用ページは戻さない。工数 S〜M（T28 に +0.5日）。
- 期待効果（数字）: 来訪→ログインを 4% → 6% に上げる仮説。§2 のとおり、来訪1,000人なら登録 +20人、会員 +1.5人 ≈ +750円/月。小さいが**恒久的に効く**うえ、ラベル印刷という特典の使い勝手そのもの。
- 撤退基準: 11月末に「リスト保存者のうち会員転換 0%」かつ「保存者 <10人」なら休止（1コミット）。

## 2. 論点 (d) 告知直後の来訪ピークをどう会員登録につなげるか — 初月の数式

### 2-1. 前提の転換率（根拠つき）

| 段階 | 想定率 | 根拠 |
|---|---|---|
| 来訪 → Google ログイン | **4%**（投稿理由のみ）／ **6%**（所有株リスト + ラベル印刷あり） | 参照系サイトで「投稿のためだけにログイン」する人は来訪の数%。手元の株に紐づく無料機能（リスト・自分の投稿分のラベル）があると、投稿予定のないコレクターもログインする。フリーミアム一般の無料→有料が「数%」であるのに対し、無料登録はその 1〜2 段上 |
| ログイン → 会員（初月） | **8%** | 初月の会員はほぼ「知人・支援動機 + ラベル印刷を今すぐ使いたい人」。実生6件目の壁に初月で当たる人は少ない。フリーミアムの無料→有料は一般に数%、告知直後は知人効果で上振れするため 8% を置く（11月には 3〜5% に落ちる前提） |
| 会員の年額比率 | **30%** | 年額を既定選択にしている（BOARD §2）。支援動機の人は年額を選びやすい |

### 2-2. 数式

```
来訪 U（告知月のユニーク）
登録  = U × 6%                （所有株リスト + ラベル印刷あり。無ければ 4%）
会員  = 登録 × 8%
月次売上（継続ベース） = 会員 × 500円
初月の現金 = 会員 × 70% × 500円 + 会員 × 30% × 5,000円 = 会員 × 1,850円
```

| 来訪 U | 登録 | 会員 | 継続ベース/月 | 初月の現金 |
|---|---|---|---|---|
| 500 | 30 | 2〜3 | 1,000〜1,500円 | 3,700〜5,550円 |
| **1,000** | **60** | **5** | **2,500円** | **9,250円** |
| 2,500 | 150 | 12 | 6,000円 | 22,200円 |

- **初月に「月1万円」を現金で越えるには来訪 ≈1,100人**（年額の前払いが効く）。**継続ベースで会員12人（BOARD の12月目標）には累計 ≈2,500人**が必要。これは告知1回では届かず、告知 1,000 + 9〜12月の検索流入（20件追加・`/names/`・Monstera 公開）で 500/月 × 3 を積む前提で成立する。
- 所有株リストが無い場合（4%）: 来訪1,000で会員 3人、継続 1,600円、現金 5,900円。差は会員 2人 ≈ 月1,000円 + 初月現金 3,400円。

### 2-3. 告知の時期（収益上の最重要点）

**決済が動いていない状態で本告知してはいけない。** 来訪ピークの人は大半が戻ってこないので、ピーク時に「会員になる」ボタンが「準備中」だと、初月の会員はほぼゼロになり、上の表の右2列が消える。

告知の2段階:
1. **ソフト告知（今〜9/20）**: 知人ブリーダー・@hare_anthurium 等 10〜20人に直接。目的は誤りの指摘と投稿5件。数字は追わない。

## 3. 論点 (b)(c) アフィリエイト — Amazon の180日ルールと3社比較、トップ道具棚

### 3-1. トップ道具棚の期待売上（信頼感 vs 初期売上）

```
トップ PV           = 月PV × 30%        （3,000PV → 900、8,000PV → 2,400）
棚クリック率         = 0.5〜1%           （参照系サイトのトップに置いた商品グリッド）
クリック → 成約      = 2〜3%             （24時間クッキー、購買モードで来ていない）
成約単価 × 料率      = 5,000円 × 2〜3% = 100〜150円（楽天は1商品1,000円上限）
```
→ 9月末水準で **月 約10〜40円**、12月水準でも **月 約30〜100円**。会員1人（500円）を1人でも逃せば赤字。**初期売上は取らない。信頼感を取る。**

### 3-2. 3社比較（2026-09 時点、公開情報）

| | 楽天 | Yahoo!（バリューコマース） | Amazon |
|---|---|---|---|
| 料率 | ジャンル別 2〜4%、**1商品あたり報酬上限 1,000円**（高料率商品は除外） | 店舗が 1〜50% で任意設定、多くは 1% 前後。VC 手数料 30% は店舗負担 | カテゴリ別、ホーム&キッチン・DIY・本は概ね 3%、家電系 2%。2024-08 に紹介料上限を廃止 |
| クッキー | クリック後 24時間以内にカゴ投入 → 89日以内に購入 | 24時間 | 24時間（カゴ投入で90日） |
| 審査 | 楽天 ID で即時 | 提携審査あり（既存リンク有効） | 登録後 **180日以内に適格販売3件**、達成後に目視審査。自己購入・知人購入は無効。未達でアカウント閉鎖（再申請可） |
| 当サイトでの強み | 用土・鉢・温湿度計・LED など道具全般。オーナーが ID 連携すれば即発行 | 楽天と同じ商材の比較先。単独では弱い | **洋書・専門書**（Bown *Aroids*、Croat のモノグラフ、Exotica 等）。出典として引く本を「本そのもの」に繋げられる |
| 判定 | 主軸（現状維持） | 補助（現状維持） | **出典書籍限定で条件付き** |

クッキーは3社とも24時間で差が無くなったため、「どこに送るか」は料率より**商材の有無**で決まる。道具は楽天、書籍は Amazon という分担が自然。

### 3-3. Amazon「180日3件」は告知後なら満たせるか

```
必要クリック数 = 3件 ÷ 成約率 3% = 100クリック / 180日 ≈ 17クリック/月
```
- BOARD の KPI は affiliate_click 30/月（9月末）→ 100/月（12月末）。**書籍リンクだけでこの半分を取れれば 180日で 3件は届く**。ただし書籍は道具より単価が高く（3,000〜15,000円）購入頻度が低いので成約率は 1〜2% に落ちる可能性があり、その場合は 150〜300クリックが必要。
- 失敗のコスト: アカウント閉鎖（再申請可）と、その間の手戻り。金銭的損失はない。
- 結論: **やれるが、急がない**。楽天・Yahoo! の棚が実際にクリックされている（2ヶ月連続 ≥60/月）ことを確認してから申請する。それまでは出典書籍の欄に**リンク無しの書誌**（著者・年・ISBN）を載せておく。書誌そのものが資料館の価値で、リンクは後付けで良い。
- 実装済み資産: admin の affiliate フォームに `amazon` 列は残っている（`wireframe/admin.html:2672`）、`renderAffiliateBanner`（`wireframe/js/forms.js:2074`）からの出力だけ外れている。復活は S。
- 規約上の注意（復活時）: フッターに「Amazon のアソシエイトとして、Aroid Origins は適格販売により収入を得ています。」を常時表示／価格を本文に書かない／メール・PDF・印刷物（標本ラベル）にリンクを入れない／`rel="nofollow sponsored"` 維持／PR 表記はステマ規制で楽天・Yahoo! と同様に見出し直下。
