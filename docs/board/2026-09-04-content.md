**原種は Croat 記載が 8 種（1978〜2010）、19世紀のリンデン/ヴィーチ系が 6 種、コロンビア 10・パナマ 5・メキシコ 1・エクアドル 1・ペルー 1・仏領ギアナ 1。** 「人物」「産地」「年代」の3軸でページを切れるだけの構造化データが既にある。

### コードで見つけた、コンテンツ施策を止める不具合（先に直すべき）
1. **交配式が specimen label / 関連品種に出ない**: `wireframe/js/archive.js` の `describe()` は `entry.formula`（`_type:'formula'` の origin）と `structured.parentA` しか見ていないが、実データは `structured.formula.parentA/B` に入っている（'Dark Mama'、'Galaxy'、'Mystique a88'、実生2件すべて）。`forms.js:653` は `editStructured.formula` を読んでいるので、archive.js 側の読み漏れ。これを直さないと「交配系統図」「この品種を親に持つ交配」が全部空になる。
2. **OGP の説明文が空**: `supabase/functions/share/index.ts` は `best.description_jp` / `best.description` を読むが、origins の実フィールドは `body` / `body_en` / `structured.notes`。SNS カードに由来文が出ていない可能性が高い（X/Instagram 導線の要）。
3. **timeline から crystallinum が落ちている**: publication_year が空（Linden & André, 1873）。gloriosum / melanochrysum（非公開）も同様。年表の目玉種が欠けている。
4. **URL に使われる品種名の表記ゆれ**: `debile(debilis)`（画像テーブルには `Anthurium debilis` も別名で存在）、`aff.besseae`、`sp.peru`、`'Anthurium forgetii x 'Titanium''`、画像テーブルの `Anthurium テスト`。SEO 上は canonical が汚れる。taxonomy-editor と連携して命名規則を決めてから静的スタブを再生成したい。

### 主要競合
- **アンスリウムジャパン（anthurium-japan.com）**: 最大の競合。育て方 + 用語表 + 原種解説 + 個別品種（BVIT、Angel's Dream、luxurians、magnificum）。'Angels dream' の来歴（KUNZO 氏・花宇宙への問い合わせ）を独自取材で書いている。**由来の一次出典（記載論文・GBIF）は付けていない**。当サイトは「出典つき」で差別化し、育て方は書かない。
- **tokyoplants media / jolienursery aroids-wiki**: ショップ系メディア。品種 × 育て方。由来は 1〜2 行。
- **4aroids.de / anthuriumcollectorsguide.com（英語）**: 交配式データベース。日本語版が存在しないのがそのまま当サイトの空白地。

### SNS の実態
- 日本のコレクターは Instagram 中心（アンスリウムジャパン自身が「情報共有は主に Instagram」と明言）。X は相場・入手報告寄り。
- 投稿の型は「品種名 + 交配式 + ナーセリー/ブリーダー名（Space Hijau、Mr Chandra、Haji Ulih、NSE、Tezula）」。本サイトの 'Galaxy'、'Mystique a88'、'King of Spades' はまさにこの型の由来をすでに持っている。
- 日本人ブリーダー名が出るのは KUNZO（花宇宙）と、当サイト投稿者の @hare_anthurium。**「日本のブリーダー一覧」は誰も作っていない**。

### 「育て方を書くべきか」への回答
書かない。理由: (a) 上位 10 サイト全部が育て方で、後発では勝てない、(b) 由来サイトの純度が商品価値（product-owner 判断基準 2）、(c) 育て方は個体差・環境差で正確性の担保が難しく、誤情報リスクが由来情報の信頼にまで波及する。ただし**「自生地の環境」**（標高・雲霧林・着生）は由来情報の一部として書いてよく、そこにアフィリエイト（加湿器・LED・着生用資材）を自然に置ける。

## 4. 投稿者獲得の仕掛け

### 最初の投稿までの摩擦（現状）
1. Google ログイン必須 → 2. 品種名入力 → 3. タイプ選択 → 4. AI 由来調査 30〜90 秒待ち → 5. 投稿。
実生は無料 5 件だが、**投稿した後に何が得られるかがページに書かれていない**（`login-benefits-card` はログインのメリット止まり）。

### 報酬設計（Claude Code）
- **投稿するとブリーダーページができる**: 実生・交配種を投稿すると `/people/<breeder>/` が自動生成され、自分の交配が系統図に載る。投稿フォームの冒頭にこれを明記（「あなたの名前で人物ページが作られ、交配が系統図に記録されます」）。
- **実生ページの OGP を貼りたくなる形に**: 版画風の og-image に「交配式 + 播種日 + ブリーダー名」を焼き込む。Instagram のプロフィールリンクや X の固定ポストに貼れる「自分の台帳」に見せる。
- **シードコンテンツ**: オーナー自身で **実生を 5 件以上**、交配種を **5 件**（'Dorayaki'、'BVIT'、'Black Velvet'、'Michelle'、'RVDP' など日本で流通量の多いもの）入れる。空の系統図には誰も載りたがらない。
- **投稿後の導線**: 投稿完了画面に「X でシェア」「Instagram 用テキストをコピー」ボタン（下記テンプレ）を置く。

### 離脱率（品種ページの次の一手）
- 関連品種ブロックは実装済みだが、交配式が読めていないので「この品種を親に持つ」「兄弟」が空（§0-1）。修正すれば 'Dark Mama' ページから warocqueanum / papillilaminum / 'Dark Mama' × 'Ace of Spades' へ流れる。
- 写真なし・由来薄いページ（aff.besseae、sp.peru、antolakii）は「未確定」ラベルを付け、「この品種の由来をご存じの方は追加を」の CTA を出す（空ページを投稿導線に変える）。

## 5. オーナーへの依頼（オーナーにしかできないこと）

1. **写真撮影**（優先度高）: clarinervium、regale、luxurians、moronense、nutibarense、sagittatum。手元にない種はそのままでよい。1 枚でよい、葉 1 枚のアップで十分。
2. **シード投稿**: 自分の実生 5 件以上、流通の多い交配種 5 件（'Dorayaki'、'BVIT'、'Black Velvet'、'Michelle'、'RVDP'）。AI 由来調査後、明らかな誤りだけ直す。
3. **SNS**: Instagram / X のアカウント有無を確認し、週 3 回「今日の一葉」を上記テンプレで手動投稿（自動化は次フェーズ）。
4. **知人ブリーダーへの声かけ**: @hare_anthurium に人物ページ完成を連絡。ほか 2 名に「系統図に載せる」誘い。
5. **判断**: (a) 育て方を書かない方針の承認、(b) 人物ページに存命ブリーダー（Haji Ulih、Mr Chandra、Space Hijau、KUNZO）を載せる際の表記（Instagram ハンドルのみ／実名）ルール、(c) 10 月の Monstera 公開の可否。
6. **テストデータ削除**: 画像テーブルの `Anthurium テスト`、`Anthurium debilis` の重複画像は管理画面から削除（Claude Code が SQL を用意する）。
