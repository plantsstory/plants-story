### 3-2. PAY.JP 申請の具体手順（公開情報で確認、2026-09-07）

- **前提（最重要）**: PAY.JP は個人事業主の本番利用申請で **開業届の控え（または受領日入りの直近の確定申告書控え）** を求める（ヘルプ「個人でも利用できますか」「審査の際に提出が求められる届出証や許可証」）。マイナンバーはマスキング、届出住所から転居していれば異動確認書類も必要。→ 開業届が無いと申請自体ができないので、**9/26 に e-Tax で提出**しておく（既定。オーナー方針「開業届より品質を先に」は「順番」の話で、告知の前提条件になった時点で先送りしない）。開業届は Stripe が承認された場合も無駄にならない（青色申告・屋号口座・取扱店掲載の請求書に使う）。
- **料金**: 2024-06 のプラン改定でスタンダードは月額 0 円・決済手数料 **一律 3.3%**（旧ベーシック 3.0/3.6% は終了）。Stripe 3.6% との差は 500 円あたり 1.5 円で判断材料にならない。入金は月 1 回（末締め）または月 2 回。
- **審査期間**: 本番利用申請後 **3〜4 営業日**。確認されるのは商材の内容・金額・決済対象者・サービス提供の流れ。
- **申請フォームの記載**（`docs/stripe-application.md` §3 の説明文を流用、金額だけ 500/5,000 に置換）: サイト URL `https://plantsstory.com/`、特商法 URL `https://plantsstory.com/tokushoho/`、利用規約 `/terms/`、事業内容「アロイド植物の由来を記録するウェブ図鑑。閲覧無料。有料は会員（月500円/年5,000円、自動更新、トライアルなし）のみ。物品・植物の販売なし」、決済対象者「日本国内の個人」、提供の流れ「Google ログイン → 会員申込 → カード決済 → 即時有効 → プロフィールから解約」。
- **サイト側で PAY.JP 用に直すもの**（Claude Code、1h）: 特商法・料金・paywall の決済事業者名、`window._PAYMENT_PROVIDER`、paywall のカード入力（`#payjp-card-element` は残っているので表示を戻すだけ、`app-core.js:1791-1806`）、CSP に `js.pay.jp`。
- **リスク**: PAY.JP は「デジタルコンテンツ・会員制」を扱えるが、審査で「サービス提供の流れ」の追加質問が来ることがある。その場合、サイトの「使い方」ページ（⑦で短縮したもの）を URL で示す。

### 3-3. 決済なしで告知する場合の会員導線（10/24 の既定）

「近日」表示は **可**。ただし条件付き:

1. **価格は出す**（500/5,000）。「準備中」だけでは検討すらされない。特商法・規約は「販売価格」を掲載しつつ「受付開始日は本ページで告知」と 1 行。
2. **押せないボタンを置かない**。paywall・料金ページ・プロフィールの「申し込む」を「**開始したら知らせる**」に差し替え（ログイン済みなら `profiles.notify_member_launch=true` を立てるだけ、未ログインならログイン → 立てる）。migration 1 列 + RPC 1 本 + GA `member_interest{source}`（S、1h）。
3. 開始時の通知は**サイト上のバナー 1 行 + メール 1 通**（Resend は `stripe-webhook` で使用済みなので追加コストなし）。
4. 実生6件目は**受付開始まで上限を一時解除しない**（無料で通した人を後から有料に戻すほうが摩擦が大きい）。paywall に「会員受付は準備中です。開始したらお知らせします」と表示し、`member_interest` を取る。
5. ラベル印刷は既決どおり決済稼働までログイン全員に無料。
6. `member_interest` の件数が**初月の会員上限の見積り**になる（登録者の 10〜20% が押す想定。押した人の 30〜50% が実際に払う）。
