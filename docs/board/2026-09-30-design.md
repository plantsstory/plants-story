## 1. 画面構成

**結論: 2階層（`/tools/` 目録 + `/tools/<slug>/` 道具の1頁）。一覧内の展開（アコーディオン）は採らない。**

理由: ①「本格的」の実体は URL・パンくず・共有・被リンクを持つことで、展開は検索結果にも Instagram にも残らない。②本サイトは既に「台帳の行 → 1頁」の操作モデル（品種・人物・産地）で統一されており、道具だけ別の操作を持ち込むと学習が増える。③375px でアコーディオンは押し外し・スクロール位置飛びが起きる。

### 1-1. `/tools/`（目録）の縦順

1. パンくず `Home / 道具の目録`
2. mono 標題行 `TOOLS — 道具の目録 · 18 ITEMS · 8 GENRES`
3. h1「道具の目録」＋ Shippori 1文「自生地の条件（雲霧林・着生・標高）に対応する道具を、使った記録とともに並べます。育て方は書きません。」
4. **PR 1行**（第4節）
5. ジャンル目録（`.index__` 流用、件数つき）
6. `.sort-bar`（検索窓 + 並び順 chips + ジャンル chips）
7. `.ledger-table`（道具の行）
8. 0件は `.sheet--search`「該当なし」＋「別のジャンルを見る →」
9. 出口 mono 1行「Anthurium の台帳 → · 産地索引 →」

### 1-2. `/tools/<slug>/`（道具の1頁）の縦順

品種詳細と同じ読み順の型（標題 → 名前 → ラベル → 図版 → 本文 → 出口）を踏む。

| 順 | 要素 | 中身 |
|---|---|---|
| A | mono 標題行 | `TOOLS · 用土・軽石 · NO. 007` |
| B | h1 | 道具の一般名（「日向土 小粒 18L」。ストアの長い商品名は使わない） |
| C | cite 行 mono | `メーカー · 型番 · 1,000〜2,000円` |
| D | **道具ラベル**（`.specimen` 流用） | ジャンル / メーカー / 型番・規格 / 容量 / 価格帯 / 対応する条件 / 収録・更新 |
| E | 図版 1枚 | 楽天画像（第3節）。無ければ `.sheet--plate`「図版なし」 |
| F | **この道具の記録**（2〜4行、オーナーの言葉） | 事実のみ（何年から何に使っているか、粒径、水の抜け、割れやすさ）。**用量・頻度・手順は書かない**（BOARD「育て方は書かない」との整合線） |
| G | 対応する自生地条件 + 該当原種 1〜3件 | mono 1行「着生 · 雲霧林 · 1,200-1,800m」＋品種リンク。該当0なら区画ごと非表示 |

| I | 収録メモ mono | `収録 2026.10.06 · 更新 2026.10.06 · 価格と在庫は各ストアの表示が最新です` |

**索引方針（品格と SEO の両立）**: `toolGate(tool)` を1関数で置く。合格 = ジャンル・メーカーまたは型番・価格帯・購入先1件・**オーナーの記録 80字以上**の全てが揃う。合格だけ静的スタブと sitemap、不合格は `noindex`（薄いアフィリエイト頁を検索エンジンに出さない）。`/tools/` 自体は常に index。

## 2. ジャンル検索 UI

「細罫の索引」の系で、**属ページの `.sort-bar` をそのまま流用**する（新しい操作系を作らない）。

### 2-1. 3層構成

1. **ジャンル目録**（`.index__group` / `.index__list` / `.index__item` / `.index__name` / `.index__count` 流用）— 8ジャンルと件数を細罫の行で並べる。押すと絞り込み（画面遷移せず chip を同期、`?g=<genre>` を `replaceState`）。「本格的」の見た目はここが担う。
2. **`.sort-bar`** — `.search-bar.search-bar--inline`（プレースホルダ「道具を検索…」）+ `.chips`（並び順: ジャンル順 / 価格帯 / 新着）+ `.chips.filter-chips`（`.chip.filter-chip` でジャンル8 + すべて）。`app-core.js:1421-1438` の生成コードと同じ DOM を使う。
3. **`.ledger-table`** — 行そのもの。

ジャンルは8固定（mono 英字 + 日本語）: `SOIL 用土・軽石` / `POTS 鉢` / `MOSS 水苔・ベラボン` / `NUTRIENT 肥料・活力剤` / `LIGHT 照明` / `AIR 加湿・送風` / `HEAT 保温・温室` / `MEASURE 計測・道具`。増やさない（9個目が必要になったら統合する）。

### 2-2. 375px の並びと寸法

- 縦順: h1 → PR → ジャンル目録（`archive.css:728-733` の `columns: 2` で2列・1行44px）→ 検索窓（全幅）→ 並び順 chips（1行）→ ジャンル chips（2行に折返し）→ 台帳。
- タップ寸法は既存の `@media (pointer: coarse)`（`archive.css:681-685`）が `.chip` と `.index__toggle` を 44px にしている。`.chip.filter-chip` も同セレクタに含まれるため**追加指定は不要**。
- chips の横スクロールは採らない（隠れた選択肢は押されない。2行の折返しで全ジャンルを常時見せる）。

### 2-3. 台帳の行（`.ledger-table` 再利用、列だけ差し替え）

- PC: `NO. / 道具名 / ジャンル / メーカー · 型番 / 価格帯(right)`。
- 640px以下: `archive.css:736-748` の grid-areas 方式に合わせ `"no name price" "no meta genre"`。`.ledger-table__no` は `NO.`、`.ledger-table__name` は道具名、`.ledger-table__meta` に `メーカー · 型番`、右に価格帯（`.ledger-table__year` と同じ mono 黄土・`tabular-nums`）。**一覧にサムネイルは出さない**（第3節）。

## 3. 画像

**推奨: 一覧は写真なしの「文字の目録」。写真は詳細ページに1枚だけ、固定枠で。**

- 理由: 楽天の画像は白背景・縦横比・解像度がばらばらで、並べると目録の罫が揃わない。Amazon 画像は自前保存が規約違反、Yahoo! も商品により差し替えが起きる。参照のみの外部画像は referrer 制約や差し替えで**いつか必ず割れる**。一覧が割れた画像の格子になるのが最悪の絵。
- したがって一覧の識別子は **mono の型番 + ジャンル + 価格帯**。これは標本ラベルの語彙と同じで、Field Archive では写真より強い。
- 詳細ページの図版枠 `.tool-plate`: `aspect-ratio: 4/5`、紙2色の台紙、`object-fit: contain`、`mix-blend-mode: multiply`（白背景を紙に溶かす。`archive.css:316` で既に使用）、`referrerpolicy="no-referrer"`、`loading="lazy"`。`onerror` と5秒タイムアウトでは**絵文字を入れず** `.sheet--plate`（mono `PLATE — 図版なし`）に差し替える。
- 将来: オーナーが道具を紙の上に置いて撮った俯瞰写真（第7節-3）に差し替えられる設計にする（`image_own` 列を優先、無ければ楽天画像）。版画変換（T35）の素材にもなる。

## 4. PR 表記

置き方は3箇所・mono 1行のみ。バッジ・色枠・太字は使わない（目立たせすぎず隠しもしない = 罫線の直上に常時、読み飛ばせない位置）。

1. `/tools/` の h1 直下: 「PR — このページは楽天・Yahoo!ショッピングのアフィリエイトリンクを含みます。」
2. 詳細ページ、購入先リンクの**直上**（罫線の上）: 「PR — 以下のリンクから購入があった場合、運営者に紹介料が入ります。掲載は運営者が実際に使っているものに限ります。価格と在庫は各ストアの表示が最新です。」
3. 原種ページ末尾の1〜2点の見出し行: 「道具 — PR」（`.affiliate-banner__context` を流用）

- 既存文言「※ 上記はアフィリエイトリンクです。購入によりサイト運営をサポートできます。」（`translations.json:439`）は依頼調をやめ上記2に差し替え。「管理人おすすめアイテム」「Staff Picks」（`:455/459`）も撤去し、見出しは「道具の目録」「この条件に対応する道具」に。`.affiliate-card__recommend`（おすすめ）と `badge` は /tools/ では使わない。
- 価格は**帯のみ**（「1,000〜2,000円」）。実売価格・値引き率・「最安」は書かない（BOARD「相場は扱わない」）。

## 5. 図鑑本体との導線

**推奨（1つに決める）: フッターに「道具」1リンク + 原種詳細ページ末尾に1〜2点（T34 の条件つき）。ヘッダーには入れない。**

- ヘッダー6要素は動かさない。道具は「由来を読む・確かめる・書き足す」に直接効かないので、ヘッダーに入れた瞬間にサイトの定義が変わる。
- 原種詳細の1〜2点は T34 の決定どおり **自生地環境（標高・雲霧林・着生）を持つ原種のみ**。3点以上並べない（2点までなら「文脈」、3点からは「棚」）。文言は「この種の自生環境に近い道具」、末尾に「道具の目録 →」。
- 産地ページ（`/locality/<country>/`）末尾にも同じ部品で1〜2点（BOARD で掲載可の面）。
- トップ・属ページ・Hybrid/Clone/実生・人物ページには出さない（X1 の削除を含む）。

## 7. オーナーへの依頼

1. **道具データ 12〜20点**（目録として成立する下限は「6ジャンル × 2点」）。1点につき: ジャンル / 道具の一般名 / メーカー / 型番・規格 / 容量 / 価格帯 / 楽天URL / Yahoo!URL / **自分の使用記録 2〜4行**。記録は「何年から何に使っているか・粒の大きさ・水の抜け・欠点」まで。用量や頻度（= 育て方）は書かない。管理画面「アフィリエイト」から直接入力できるようにします（P0）。
