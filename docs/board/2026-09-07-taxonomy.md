## 4. 用語集（案、各 60〜100 字）

| 語 | 定義 |
|---|---|
| 個体 | 原種の1株に付けた番号や名前（'HR1' など）。株分けや組織培養で増えた株も同じ個体。実生で生まれた子は別の個体で、親の名前を引き継がない。 |
| 系統（line） | 同じ名前で世代を重ねた実生が流通している集団。遺伝的に異なる株を含むため、その名前は1個体ではなく「系統」を指す。本サイトではタグ line で示す。 |
| F1 | ある交配で得た実生の第1世代。同じ交配式でも個体ごとに形質は異なるため、F1 の株は名前つきのオリジナル個体（クローン）とは区別して扱う。 |
| オリジナル個体 | その名前が最初に付けられた1株。分け株・組織培養の株は同一個体だが、実生（F1 以降）は別個体。本サイトの品種名はオリジナル個体を指す。 |
| 管理番号 | 生産者や愛好家が個体の識別に付ける番号（'HR1'・'A88'）。品種名と同じシングルクォートで書き、命名者と命名年を添える。番号だけでは種を示さない。 |
| 未収録 | 記録はあるが、区分ごとの必須項目（記載者・年・出典、交配式・作出者、播種日など）が揃わず品質ゲートを通っていない状態。検索エンジンと件数には出さない。 |
| 記載者 | 学名を有効に発表した著者。IPNI の標準略称（Croat、N.E.Br.）で書く。採集者・導入者・命名者とは別の役割で、混同しない。 |
| タイプ産地 | 学名の基準となる標本（タイプ）が採集された場所。原記載に書かれた地名だけを載せ、現在の分布（POWO）とは区別する。不明なら空欄。 |

## 5. 削るべきもの（正確性を下げる要素、3 件）

1. **forgetii(11)・regale(83) の第2記録（manual・trust 95・verified true）** — IPNI 記録の劣化コピーで、形態テンプレ文・サイズ文・誤り（平行脈）を structured.notes に保持。「検証済」印が付いたまま台帳の「由来 2件」を水増ししている。削除。
2. **IPNI 型データに無い採集者・採集年**（carlablackiae 2009、clarinervium E. Matuda 1949、regale Gustav Wallis、moronense 1967、kunayalense 2007）— 09-05b で決めたルールの例外が残ると、人物索引（collector ロール）に根拠のない項目が再び立つ。NULL に（D3・D4）。
3. **'Dark Mama'(5) の AI 本文（Llama 3.3、出典 0）** — 「プライベートブリーダーによって開発されたと考えられています」は推測。折り畳んでも詳細ページに残る。削除して「記録なし」に落とし、P5 の両論併記まで空にしておく方が誠実。
