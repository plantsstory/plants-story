## 3. やらないこと（理由つき）

| やらないこと | 理由 |
|---|---|
| 品種ページに「楽天・Yahoo!で この名前を検索」（生きた植物のアフィリエイトリンク） | 通販の出品名には取り違え（Hybrid を「クリスタリナム」として出品するなど）が多く、名前の正確さを売りにする図鑑がそこへ送るのは自己否定になる。取扱店（有料）と同じ場所で競合する。第 5 回の配置の決まり（文字行は原種・産地だけ、カードなし）にも反する |
| AdSense | 決定済み（30,000PV かつ 会員 5 人未満で再議題）。いまの PV では月 100 円未満で、読む画面の信頼を削る |
| 投げ銭（OFUSE・FANBOX・Ko-fi）、PayPay の個人間送金で会費を受け取る | 「応援」「支援者」は禁止語。PayPay の個人間送金を商用に使うのは規約違反。会員と二重の管理になる。振込の年額（施策 8）で足りる |
| BASE・STORES で「会員権」を売る | 各サービスの禁止商材の判断が不確かで、手作業で会員資格と同期する必要もある。振込なら手数料 0 で、特商法の表記も 1 か所で済む |
| 値上げ・値下げ・期間限定の割引・「先着」「創設会員特典」 | 価格は 2027-02 まで凍結。「限定」「今だけ」は禁止語。価格を動かすと、名簿の人に別々の約束をすることになる |
| 告知文で道具ページを押す | 決定済み（告知 +1 週にストーリーズで 1 回だけ）。初対面の印象を物販にしない |
| 取扱店を品種ごとに売る・「認定店」「提携店」と呼ぶ | 「この店がこの品種を売っている」は確かめられない。認定や提携は、当サイトが品質を保証したと誤認させる |
| メール・ラベルの QR・PDF に Amazon のリンクを入れる | Amazon アソシエイトの規約はメール内やオフラインでのリンクを禁止している。QR は自分の品種ページだけにする |

## 4. やってはいけないこと（表示と規約の線）

- **ステマ規制**（景品表示法の指定告示、2023-10-01 施行）
  - アフィリエイト・取扱店・運営者の店には「PR」をいつも付ける。目録は h1 の下、商品ページは購入ボタンの直上、取扱店は欄の見出し、文脈行は見出しに付ける。
  - PR の文字は 12px 以上で、「PR —」は黒。PR を折りたたみの中・画像の中・ページ下部だけに置かない。
  - 店の一言（40 字）は店の言葉として PR 欄にだけ出し、運営者の感想に見せない。
- **禁止語**: おすすめ／最安／ランキング／No.1／人気／効く／効果／改善／治る／限定／今だけ／応援／支援者／プレミアム／Pro。星・バッジ・「売れ筋」の表示も足さない。
- **肥料・活力剤**: 商品名・成分表示・容量だけを書く。効能・用量・頻度・「元気になる」は書かない（優良誤認になり、薬機法のような書き方にも見える）。
- **価格**: 楽天の価格は「楽天市場での価格（YYYY.MM.DD 時点）」の形でだけ出す。Amazon の価格は出さない。
- **誤認**
  - 押せない申込ボタンは置かない。
  - 「お知らせします」は施策 2 で仕組みを作るまで、約束の文として書かない（いまの文は施策 2 と一緒に直す）。
  - 取扱店の掲載が記録・信頼度・検証に影響しないことは、いまの文のまま維持する。
  - 運営者の植物販売は About で開示する。
- **特商法**
  - 振込の受付を開く日に、支払方法・支払時期・提供時期・「自動更新なし」を更新し、最終確認の画面を置いてから開く。
  - 所在地と電話はオーナーの決定どおり「請求があれば遅滞なく開示」のまま。ただし PAY.JP のヘルプは電話番号の省略を「審査で指摘が入る可能性がある」としている（依頼 1 を参照）。
- **アフィリエイトのリンク**
  - href は 1 文字も変えない。短縮・自前のリダイレクト・cloaking はしない。
  - もしもの imp 画像は lazy なしで残す。楽天の画像は加工せず、楽天のリンクで包む。Rakuten クレジットは原文のまま。
- **メール**: お知らせのメールは、名簿に自分で入った人にだけ 1 回送る。宣伝のメールにはしない（特定電子メール法）。
