## 1. 月1万円の数式

### 1-1. 前提（現実的な数字）

- **決済手数料**: PAY.JP は固定費0円・決済手数料 3.0〜3.6%（ブランド/プランで変動）。定期課金機能に追加費用なし。240円プランの手取りは約232円。
  ([PAY.JP 料金体系](https://pay.jp/plan), [PAY.JP 手数料解説](https://enhanceit.jp/pay-jp-tesuryo/))
- **サブスク相場**: 日本のクリエイター支援は月額300〜800円が主流、FANBOX の1人あたり平均支援額は約500円。note メンバーシップも「500円」が最多価格帯。
  ([FANBOX 2026データ](https://app-tatsujin.com/pixiv-fanbox-2026-revenue-guide/), [note メンバーシップ相場](https://note.com/dekiruhazulab/n/neee0f33ce12f))
- **アフィリ料率**: 楽天「花・ガーデン」は概ね2〜4%、報酬上限は1商品1,000円/件、料率アップショップは最大20%。Amazon「DIY・工具・ガーデン」は3%（2024年8月に上限撤廃）。Amazon は**180日以内に適格販売3件がないとアカウント閉鎖**。
  ([楽天 料率](https://note.com/rakutenaffiliate/n/n7fbdf72f8f60), [Amazon 紹介料率](https://affiliate.amazon.co.jp/promotion/advertisingfeeschedule), [Amazon 審査条件](https://charagoo.jp/amazon-associate/))
- **広告RPM**: 趣味系ブログの AdSense RPM は 200〜300円/1,000PV。
  ([RPM目安](https://nobutoblog.com/page-rpm/), [アドセンス1万円のPV目安](https://life-money-create.com/adsense-10000yen/))
- **トラフィック**: 現状は「小さい」（GA4 未集計だが、登録6人・実生2件から月1,000〜2,000PV 程度と推定）。

### 1-3. 月1万円の数式（3〜4ヶ月後、月5,000〜8,000PV・登録60人を想定）

```
① 支援者プラン   500円 × 8人                     = 4,000円
② 由来調査リクエスト（単発） 500円 × 4件          = 2,000円
③ 取扱ショップ掲載枠   1,000円 × 2店              = 2,000円
④ アフィリエイト（品種文脈・高単価LED/用土）       = 1,500円
⑤ 実生プラン 240円 × 2人                          =   480円
                                            ─────────────
                                              合計 9,980円 ≒ 1万円
```

**数式のポイント**
- 「1万円 ÷ 240円 = 42人の有料会員」は登録6人の現状から見て非現実的。**単価の高い①②③を足して人数依存を減らす**のが最短。
- ①〜③はいずれも既存の PAY.JP 導線（Customer + Subscription / Charge）で実装でき、外部サービスの新規契約は不要。
- ④は Amazon の「180日3件」ルールがあるため、**楽天・Yahoo!（ValueCommerce）を主軸**にし、Amazon は月2,000PV を超えてから登録する。

## 3. 価格の妥当性

| 論点 | 判断 | 根拠 |

| 240円は安すぎるか | **「実生投稿」の対価としては妥当。「支援」の対価としては安すぎる** | 支援型の相場は500円。240円は「決済手数料3.6%を引くと232円」で、1人あたりの手取りが小さく、42人必要になる |

## 4. アフィリエイトの規約上の注意（現状コードのレビュー）

- **Amazon**: 商品画像は Amazon が提供するURL（PA-API / アソシエイト・セントラルのリンク生成）を使う必要があり、**画像のダウンロード・自サーバー再アップロードは禁止**。現状は楽天画像を使い Amazon は amzn.to テキストリンクのみ → **Amazon の画像規約には抵触しない**（OK）。ただし PA-API は「売上実績後に審査」なので当面は使えない。
  ([Amazon 商品紹介の注意](https://affiliate.amazon.co.jp/help/node/topic/GKT6X2R3NGW5V23K), [PA-API 要件](https://affiliate.amazon.co.jp/help/node/topic/GVJ2BJP35457CLML))
- **Amazon 180日ルール**: 登録から180日以内に適格販売3件（自己購入・家族は不可）がないとアカウント閉鎖。**月2,000PV未満の今は登録しない**。楽天・Yahoo!（ValueCommerce）で先に実績を作る。
- **楽天**: 楽天の画像リンク（hbb.afl.rakuten.co.jp）を Amazon / Yahoo! 行きボタンと同じカードに置く現状は、楽天規約上「楽天の画像を他社リンクの装飾に使う」形に見えるグレー。**カード画像は楽天ボタンのみに紐付ける**か、`referrerpolicy` を維持したまま「画像クリック＝楽天」に統一するのが安全（S、Claude Code）。
- **景表法・ステマ規制（2023年10月〜）**: 規約8条にアフィリ開示あり（OK）。品種ページの「管理人おすすめアイテム」見出しの直下に **「PR / アフィリエイトリンクを含みます」を小さく常時表示**すべき（現状は規約ページのみ）。M4 のショップ枠も「PR」表記必須。
- **rel属性**: `rel="nofollow sponsored noopener"` 実装済み（OK）。

## 5. 広告（AdSense）の可否

**当面は「やらない」（プレースホルダは非表示のまま）。**
- 趣味系 RPM 200〜300円 → 月1万円には **月33,000〜50,000PV** が必要。現状の30倍以上。
- 「学術的な由来図鑑（Kew / GBIF 由来）」という信頼感に対して、自動広告の見た目コストが大きい。今日のリデザイン（紙とインクのフィールドアーカイブ）とも相性が悪い。
- 再検討ライン: **月20,000PV を超えたら**、品種ページ最下部1枠のみ（インフィード型・自動広告OFF）で審査申請。それまでは規約9条・プライバシーポリシーの「導入予定」表記のままで問題なし。

## 7. やらないこと（と理由）

| やらないこと | 理由 |
|---|---|
| **閲覧の有料化（由来本文・高解像度写真のペイウォール）** | 由来テキストは SEO の全て。閲覧を閉じるとインデックスも信頼も失う。写真は40枚しかなく、有料化する在庫がない |
| **無料トライアルの復活** | 240円の商材でトライアルは手数料負けと解約対応コストが上回る。年額の割引で十分 |
| **AdSense の今すぐ申請** | 上記5章。PV不足で数百円にしかならず、審査落ちのリスクとデザイン毀損の方が大きい |
| **Amazon アソシエイトの今すぐ登録** | 180日3件ルールで閉鎖される。楽天・Yahoo! で実績を作ってから |
| **Stripe への再移行・複数決済の併用** | PAY.JP 移行済み。決済を増やすより「売る物」を増やす |
| **独自のEC（苗の販売）** | オーナーの手間が跳ね、規約・在庫・配送リスクが大きい。ショップ掲載枠（M4）で他店に売らせて掲載料をもらう方が軽い |
| **価格の値上げだけで1万円を狙う** | 会員0人の状態で値上げしても意味がない。単価の異なる商品（支援・単発調査・掲載枠）を足す |
