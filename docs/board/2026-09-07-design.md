## 3. 品種ごとの共有画像「標本カード」の設計（①・T29）

**方針**: 生写真を og:image にしない。すべての品種を同じ台紙 1 枚に組む。X のタイムラインで「栽培棚の写真」ではなく「図鑑の 1 頁」に見えることが目的。道具は scratchpad の `make_og.js`（`@resvg/resvg-js`、既定 OG と同じ二重罫）をそのまま `scripts/make-og-cards.js` に移し、`generate-static-pages.js:84` の `meta.image` と `share/index.ts:113` の fallback を `images/og/<slug>.png` に揃える。

- 寸法 1200×630。紙 `#F4F1EA`、インク `#1E2622`、補助 `#5B625E`、深緑 `#2F5D4A`、黄土 `#A8712E`。二重罫 28.5/36.5（既定 OG と同一）。
- 書体: 名前は **Cormorant Garamond Bold（OFL・自己ホスト）**を既定に。Georgia は CI（ubuntu）に無く再配布不可のため使わない。日本語 BIZ UDMincho（OFL）、mono は IBM Plex Mono（OFL）。3 書体を `fonts/og/` にコミットし `fontFiles` で読む。
- 写真: Storage から取得 → base64 data URI で `<image>`。`preserveAspectRatio="xMidYMid meet"` が object-fit: contain に相当。台紙は 4:5。
- 写真なし（9 件）: 台紙は残し、中央にモノグラム「A」（Cormorant 160、補助色）+ mono「PLATE NOT YET RECORDED」。`images/anthurium.png` は出所（自作か AI か）が未確認（BOARD 依頼 7）のため、確認が取れるまで使わない。
- 名前の長さで自動縮小: ≤12 字 96px / ≤18 字 76px / それ以上 58px。属は上段 mono 行が担うので大見出しは種小名・品種名だけ。
