## 2. 決定事項（最終）

各項目: 理由 ／ 担当 ／ 期限。

1. **有料オファーは「会員（Member）月500円 / 年5,000円」の1つだけ**。特典は実在する4つ（実生投稿無制限・標本ラベル印刷・会員バッジと About 一覧・再調査リクエストの48時間優先審査）。「支援者」名称と「広告非表示」「先行閲覧」は廃止。理由: ≤100人規模で2プランは分岐過多、240円は手取り231円で42人必要、存在しない特典は信頼を削る。担当: Claude Code（T30）。期限: Stripe 判定翌日。
2. **240円 / 2,500円 実生プランは廃止**。有料0人のため移行なし。**Stripe 審査中は料金・特商法・規約（現在 240/2,500 表記）を変更しない**。判定翌日に translations・3ページ・モーダル・OGP・静的スタブを一括改訂。Stripe には 240/2,500 の Price を作らず、承認後に会員 Price 2本のみ作る。不承認なら PAY.JP で会員2本。理由: 審査担当が見ているページとの相違を避ける。担当: Claude Code / オーナー（Price 作成・鍵）。
3. **由来調査の有料販売はしない（オーナー決定）**。登録時 AI 調査は無料1回、以後は無料の「AI 再調査リクエスト」（ログイン必須、理由 ≤500字、1品種 open 1件、1人 open 3件）を管理者が承認/却下、承認で実行。管理者の出典確認は「検証済」印として無償で行う。理由: 由来の無料は集客と信頼の核。担当: Claude Code（T20）。期限: 9/7。
4. **月1万円の数式を再構成**: 会員 500円×12人 ≈ 5,800 + 取扱店 1,000円×3店 = 3,000 + アフィリ 500 ≈ 9,300〜10,000円。11月末に会員5人未満なら12月目標を1月末へ後ろ倒し、価格は動かさない。理由: 980円商品が抜けた分を会員と取扱店で埋める。取扱店は12月末に有料0店なら廃止。
5. **AI コスト方針**: サイト 15回/日（`RESEARCH_DAILY_CAP=15`）、一般の登録起点 3回/日・10回/月、会員 5回/日、管理者無制限、登録時 検索8回/回、承認再調査 12回/回。AI 単独・未検証の記録に「AI 下書き・未検証」ラベル + リクエスト導線。想定 ≈1,200円/月。理由: 現行30回/日は最悪1.8万円/月で売上目標を超える。担当: Claude Code（T20）。
6. **無料のまま恒久**: 閲覧全部、品種登録 + AI 調査1回、実生5件、再調査リクエスト、追記・修正提案、人物ページ自動生成、投票。
7. **削除リスト（content と design を統合）**: お気に入り（ナビ・ボタン・ページ）、画像 Real/Fake 投票、トップの道具棚、トップの実生ノート区画、AdSense 枠（DOM・i18n・ポリシー文言）、YouTube チャンネル検索、ユーザー名検索、i18n 死にキー、`trial-reminder`、Amazon リンク、共有メニューの Facebook/LINE、`hero-mist.jpg`、「AI生成待ち」バッジ、「?」ポップアップ、Platycerium 18件（CSV 退避）。テーブルは残す（可逆）。担当: Claude Code（T21, T36）。期限: 9/9〜9/10。
   - 衝突の解決: **お気に入り**は両者削除で一致 → 削除。**EN 切替**は両者「フッターへ」で一致、英語補完は content/monetization の凍結を採る（design の hreflang 要望は被リンク月10件超で再検討）。**道具棚**はトップ撤去で一致、品種ページは monetization の「産地ページ + 自生地環境つき原種のみ」を採る（design の「属ページ末尾」は不採用）。**実生ノート**はトップ区画を撤去し、新着記録台帳に日付順で混ぜる。**由来の投票**は content「削除」と design「文字化して残す」が衝突 → **文字化して残す**（taxonomy の検証フローで訂正の入口として使うため）。colophon・JSON-LD の「投票で検証」文言は削除し、12月末に累計10票未満なら撤去。
