## 4. 投稿の手順
1. スマホで画像 URL を開き、長押しで保存する（告知は launch-1〜5 を順に、複数選択で）。
2. Instagram「＋」→ 投稿 → 画像を選び、左下の枠アイコンで 4:5 にする（正方形に切らない）。
3. 本文ブロックを長押しでコピー → キャプションに貼る → 20:00 ごろシェア。
4. 告知の前に、プロフィールのリンクが https://plantsstory.com/ig/ になっているか確認する。
5. ストーリーズは指定の日に、リンクスタンプで URL を付ける。
