## 1. 各レポートの要旨

### 収益（monetization）
- 現構成のまま最大化しても月500円程度。「PAY.JP キーを入れれば売れる」状態ではなく、売る物と PV の両方が要る。
- 月1万円の数式: 支援者 500円×8 + 由来調査 500円×4 + ショップ掲載 1,000円×2 + アフィリ 1,500 + 実生 240円×2。
- 支援者プラン（月500 / 年5,000）を新設。240円は実生投稿の対価としては妥当だが支援の対価としては安い。
- 由来調査リクエスト（単発500円）はコア価値そのものを売り、結果が公開コンテンツになる。
- ショップ掲載枠 1,000円/月（初回3ヶ月無料）はアフィリ3%より単価が高い。
- アフィリは全ページ同一7商品 → 属・タイプ別出し分け + 高単価（LED・温湿度計・用土）。楽天・Yahoo!主軸、Amazon は月2,000PV超まで登録しない。
- AdSense は月2万PV超まで見送り（RPM 200〜300円、デザイン毀損）。
- 法務: 特商法12条の6 の最終確認画面（本日対応済）、商品カード直下の PR 表記、楽天画像の紐付け。
- 3属再公開で検索面 2.3倍。
- 30日 KPI: PV 3,000 / 登録 20 / 有料 3 / affiliate_click 60 / 売上 2,500円。

### 分類・命名（taxonomy）
- 4区分は維持。判定軸を「1個体の栄養繁殖由来だけ（Clone）か、複数の遺伝的に異なる個体を含む（Hybrid）か」に一本化。
- sp./aff./cf. は修飾子カラム、斑入り・産地・TC・系統はタグ、流通名は `name_status`。区分は増やさない。
- ICNCP 表記: イタリック、'シングルクォート + 語頭大文字'、× は U+00D7、非公式名はダブルクォート、異名は `aliases`。
- 69件中 28件に修正が必要（名前9・区分6・本文10・構造8）。うち機械的修正は即実施可、区分5件はオーナー判断。
- スキーマ案 13列（`species_qualifier` `aliases` `tags` `name_status` `locality` `parent_a/b_id` `formula_status` …）と投稿フォームの分割入力。
- `structured.origin_type` は `cultivars.type` と重複し2件で食い違い → 廃止。
- 属ページは 原種 → Hybrid → Clone の順、詳細ページに系統ブロックと派生品種（逆引き）。
- オーナー確認 9件（種小名必須の範囲、King of Spades、Glorious ほか3件の Hybrid 化、Dark Mama 両論、sp. の書式、昇格の扱い、Albo/Aurea、Platycerium、和名）。

### 集客・コンテンツ（content）
- 「記載者・年・タイプ産地・採集者」を持つ日本語サイトは当サイトだけ。育て方は上位10件が全部で勝てない → 書かない。
- 日本語に存在しない空白: 交配式データベース、人物（記載者・ブリーダー）、日本のブリーダー一覧。
- 優先: 人物ページ → 交配系統図 → 産地ページ → 年表拡充 → 用語集 → 誤称・別名 → 英語補完。
- 最大競合はアンスリウムジャパン（出典なし）。「出典つき」で差別化。
- Instagram が主戦場。投稿の型「品種名 + 交配式 + ブリーダー名」は既存データと一致。
- 投稿者報酬: 投稿すると人物ページが生成され系統図に載る。実生 OGP に交配式を焼き込む。
- シードコンテンツ（実生5件・交配種5件）が無いと誰も載りたがらない。
- 写真なし原種 8種（clarinervium, regale …）はオーナー撮影が必要。
- Monstera 公開は Anthurium の人物・産地・系統図を完成させてから 10月。
- 発見した不具合4件（formula 読み漏れ、OGP 空、crystallinum 年欠損、URL 表記ゆれ）→ 3件は本日修正済。

### デザイン・UX（design）
- archive.css が効く画面は良い。下に旧「Tropical Shade」層（絵文字・グラデ・影・5色バッジ・カードグリッド・旧 HEX）が残る。
- モバイル 375px でタップ領域 44px を割る要素が多い（`.btn--sm` 40px、chip 33px、年表の点）。
- High: G1 タップ領域、G2 theme-color/manifest の旧緑、T1 masthead の図版が AI/ベクター調、L1 sort-bar 崩れ、D1 写真なし空状態、D2 操作ボタン列、P1 お気に入りの旧カード、F1 削除ボタン inline 色。
- 空状態を「未収録の標本ラベル」に統一（図版未収録 / 記録未収録）。
- 面白い実装 A: 写真→版画の図版パイプライン（まず CSS 試作30分）。B: 標本ラベル印刷（print.css、0.5〜1日）。
- 決済モーダル W1 の再設計はテストキーで表示のみ確認。
- 実装順: 今週 G1 G2 M1〜M4 → D1 D8 G5〜G7 P1 → F2〜F6 W1 → A/B → admin。
- オーナーへ: 図版用写真 6〜10枚、anthurium.png と og-default.png の出所、文言3件、プレビュー実機確認。

## 2. 決定事項

1. **目標**: 月1万円を 2026年12月末に達成。9月末は「PAY.JP 稼働・有料2人・登録20人・PV 3,000」。理由: 会員0の現状で30日1万円は非現実的、数式は monetization §1-3 を採用。担当: 全員。期限: 12/31。
2. **閲覧は永久無料**。由来本文・写真のペイウォールは今後も行わない。理由: SEO と信頼が商品価値（monetization §7、content、product-owner 基準②が一致）。担当: —。決定済。
3. **支援者プラン 月500円 / 年5,000円を新設**。特典: バッジ・About の支援者一覧（任意）・実生無制限・標本ラベル印刷・非公開属の先行閲覧・将来の広告非表示。実生プラン 240/2,500 は据え置き。理由: 人数依存を減らす最短経路、既存 PAY.JP 実装にプランIDを足すだけ。担当: Claude Code（コード・規約）9/12、オーナー（プラン作成）。効果: +4,000円/月（8人）。
4. **由来調査リクエスト 500円（単発）を10月開始**。理由: コア価値を売り、結果が公開コンテンツになる。9月は PAY.JP 稼働と支援者プランを優先。担当: Claude Code 10/10、オーナー（週1で公開ボタン）。効果: +2,000円/月。
5. **ショップ掲載枠 1,000円/月・初回3ヶ月無料を10月営業開始**。担当: Claude Code（`shops` テーブル・表示、DM 文面）、オーナー（DM）。効果: +2,000円/月。
6. **AdSense・Amazon アソシエイトは見送り**（それぞれ月2万PV・月2,000PV超で再検討）。楽天・Yahoo!(VC) 主軸。担当: —。
7. **アフィリの文脈化**（属・タイプ別出し分け、高単価商材、PR 常時表示、楽天画像は楽天ボタンのみ）+ Admin にファネルと商品別クリック集計。担当: Claude Code 9/21、オーナー（リンク発行）。効果: +1,500円/月。
8. **分類: 4区分維持、判定軸・ICNCP 表記ルール・「種小名必須は単一原種由来のみ」を採択**。担当: Claude Code（ガイド反映は本日済、フォームヒント・translations 9/10）。
9. **既存データ修正の [即] 項目をすべて実施**（名前9・区分2・本文6・構造8、`"null"`→NULL、プレースホルダ削除、`forms.js:1274` の合成修正）。[判] 項目はオーナー回答後。担当: Claude Code 9/10。理由: 判断基準②、可逆。
10. **スキーマは2段階**。Phase A（9月）: NULL 許容の列追加 `species_qualifier` `aliases` `tags` `name_status` `locality` `parent_a/b_id` `parent_a/b_text` `formula_status` `selected_from_id`、バッジを列参照に、`structured.origin_type` 廃止。Phase B（10月）: `species_epithet` `cultivar_epithet` `display_name` `propagation` `japanese_name` と投稿フォーム分割。理由: 13列 + フォーム改修を一度にやると1セッションで終わらず、系統図に必要なのは親リンクだけ。担当: Claude Code 9/14。
11. **育て方は書かない**。自生地環境は由来として書き、アフィリを文脈化。相場は扱わない。担当: —。決定済。
12. **9月コンテンツ順**: 人物 → 系統図 → 産地 → 用語集 → 誤称・別名 → 英語補完。理由: 人物と系統図は投稿者獲得（人物ページが報酬）と系統図（日本語圏に無い）の両方に効く。担当: Claude Code、9/17 〜 9/30。
13. **Monstera 公開は10月**（9月中にデータ修正）、Philodendron は 3件の Hybrid 化と rubrijuvenile 修正後に判断、**Platycerium は保留**。理由: monetization の「3属即再公開」と content の「Anthurium 完成後」の折衷。修正前に公開すると誤った由来が index される。担当: Claude Code（オーナー承認後）。
14. **Field Archive をデザイン方針として採択**。本番反映はオーナーのプレビュー承認後（標準手順）。今週分 CSS（G1 G2 M1〜M4 D1 D8）を同梱してから承認に出す。担当: Claude Code 9/7 → オーナー。
15. **デザインの文言・案をボードで確定**: バッジ「原種」/"Species"、属タブ「収録品種 / 実生ノート」、空状態「図版未収録 — 写真を提供する」「記録未収録 — 記録を追加する」、年表軸はモバイル非表示（案A）、About 使命文は引用文スタイル、操作列は mono リンク行（プレビューで発見性を確認）。理由: すべて可逆で、オーナーの判断負荷を減らす。
16. **図版パイプライン A は CSS 試作から**（写真到着後）、**標本ラベル印刷 B は9月末**に実装し支援者・実生の特典にする。産地地図は見送り。担当: Claude Code 9/30。
17. **投稿者報酬**: 人物ページ自動生成、実生 OGP に交配式、投稿完了画面のシェアボタン、下書き保存。存命ブリーダーは本人公開名義のみ。担当: Claude Code 9/30。
