## 2. ストアボタン・PR・価格・使用中の決まり（1つにまとめる）
- **ボタン:** サイト全体で「塗りのボタンは1ページに1つ＝そのページの主な操作」とする（ヘッダーの「+ 投稿」と同じ形。墨色・角2px・高さ44〜48px）。
  - 道具の商品ページ: 先頭のストアだけ塗り、残りは枠線1px（T58 の2px枠線は1pxの塗りに置き換える）。
  - 一覧と「ほかの道具」: 全部を枠線1px・44px にする。並びは名前 → メーカー → 価格の下で、テキストの列の左に揃える。
- **文言:** 商品ページは「{楽天市場}で見る」。一覧は横幅が足りないので「楽天」「Yahoo!」「Amazon」のストア名だけ（いまと同じ）。「購入」「今すぐ」「最安」は使わない。並び順は楽天 → Yahoo! → Amazon で固定（`SHOP_ORDER`）。
- **クリック率を落とさないために守ること:**
  1. 押せる範囲は高さ44px以上・幅48px以上。
  2. ボタンはいつも価格の直下（価格で決めた直後に押せる位置）。
  3. 商品ページのボタンは1画面目に入れる。
  4. 一覧の画像と名前のリンク先は商品ページのまま（PR と価格の日付を見せてからストアへ送る）。
  5. ボタンを文字リンクにしない（図鑑側の下線の誘導は「書き足す」用で、外部ストアと区別する）。
- **PR:** 文言と位置は変えない。読みやすくするだけにする。
  - `.pr-line` を 0.64rem → **0.72rem**（cite 行と同じ）。冒頭の「PR —」は墨色、残りは mid。
  - ステマ規制の運用基準は「一般消費者にとって明瞭」を求めており、10px のグレー文字は弱い。
  - 取扱店の欄も、見出し「取扱店 — PR」と注記を同じ 0.72rem にする。
- **価格:** mono の lining 数字。日付は「楽天市場での価格（2026.10.02 時点）」の形を全画面で使う。一覧は件数の行に1回、詳細は価格の直下。価格帯（手動の商品）は同じ書体で「1,000〜2,000円」。値が無ければ行ごと省く。

## 4. 変えない点（規約・計測・アフィリエイト規約の要件）

- **楽天:**

  - 画像のリンクは楽天の商品リンクのままにする。

- **禁止語:** おすすめ・最安・ランキング・効く・No.1。バッジ・星の数・「人気」の表示は足さない（レビュー数はデータだけにとどめる）。
