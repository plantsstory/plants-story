## 2. ラベルの項目と空欄の扱い

- **必須項目**（区分を決める項目）は、空でも「記録なし」と薄く出し、書き足す欄へリンクする。
- **任意項目**は空なら出さない。
- 375px では 1 列（項目名は左に 5em、値は右）。今の 2 列の表は、長い産地名がはみ出し、項目が奇数だと右側が空き、検証だけ枠が違う。

| 区分 | 必須（この順） | 任意（この順） |
|---|---|---|
| 原種（記載種） | 記載者 · 発表年 · タイプ産地 · 分布 | 採集者（採集年を括弧で）· 出版物 |
| 未記載・未同定（sp. / aff. / cf. / informal） | 名前の状態 · 報告されている産地 | 近縁とされる種 · 名前の出どころ · 流通名 · 導入者 |
| Hybrid | 作出者 · 交配式（不明なら「不明」、親が複数説なら「複合」） | 命名年 · 導入者 |
| Clone | 作出者（命名者が別人なら「命名者」をもう 1 行）· 元の株または交配式 | 命名年 · 導入者 |
| 個体 | 種（選抜元）· 産地 | 維持・導入者 · 命名年 |

## 3. 表記の決まり

- **学名**: 属名と種小名をイタリック。sp. / aff. / cf. / var. / ×・引用符で囲んだ名前・人名は立体。
  - 系統図の箱、ラベルの交配式・別名、一覧の交配式が今は立体のまま（archive.js:727・736・509・518、app-core.js:2584）。すべて sciNameHtml を通す。
  - 本文中の収録名（Anthurium xxx、A. xxx）も、表示時にイタリックにする。
- **交配式**: 「A. warocqueanum × A. papillilaminum 'Fort Sherman'」。同じ属は略して「A.」にする。品種名だけのときは「'Dorayaki' × 'Red Crystallinum'」。× は U+00D7 で前後に空白（x は使わない）。系統図の箱にも略記を使う（今は 3 行に折り返している）。
- **引用符**: 品種名はシングルの ' '。未記載の仮名は sp. "…"。流通名もシングルにし、ラベル下の「流通名」注記で区別する（D4 は現状維持で確定）。パンくずでも引用符を消さない（pages.js:1186）。
- **antolakii**: 一覧と見出しで、記載種と同じイタリックの二名法で出ている。URL は変えずに、表示だけ「Anthurium sp. "antolakii"」にする（表示名は species_status から作る）。
- **人名**: IPNI の標準略記をそのまま出す（T.Moore・N.E.Br.・Mast.）。人物索引の添え書きは、姓の大文字ではなく authority の ipni 欄を出す。
- **大文字化**: `.mono` の大文字指定（archive.css:20-24）が、データを大文字に変えている（PÉREZ-FARR.、N.E.BR.、COLOMBIA、CLONE、WAROCQUEANUM）。大文字は固定の UI 語（HOME など）だけにし、学名・人名・地名・区分語・出口リンクは書いたとおりに出す。チップの「HYBRID CLONE」も「Hybrid · Clone」にする。
- **国名**: 日本語画面ではラベル・一覧・索引・系統図・出口・産地ページで日本語にする。本文と同じ対応表（2026-10-03-taxonomy.md の 13 か国）を archive.js の COUNTRY_JA にして共有する。小地名だけ原綴（Chapare、Darién）。英語画面では英語。
- **国の決め方**: タイプ産地の国を使う。無ければ分布の先頭（データに入っている順）。今はコード内の国名リストの順で選ぶため、hookeri が Venezuela、sagittatum が Colombia になっている（archive.js:64-77）。
- **日付**: 画面ではすべて YYYY.MM.DD。トップの新着だけ MM.DD（列名「日付」）。
  - 播種日は今 ISO のまま「2025-11-10」で出ている（archive.js:508）ので直す。
  - 照合した日は検証の行だけに書く。本文の「（2026-10-03 確認）」と verification_note の日付は削除する。
- **年の色**: 年だけ橙色だとリンクに見える。色は一覧・ラベル・トップで同じにする（色そのものはデザイン担当）。

## 4. 一覧の 1 行（1 つの部品にする）

属一覧・トップの新着・人物と産地の台帳・関連の各リスト・検索結果は、`entryLine(d)` 1 つで描く。

- **1 行目**: 名前（イタリックの規則どおり）。右端に状態を 1 つだけ出す: ✓ n%（検証済）／n%／投稿者の記録／未収録。
- **2 行目**（小さめ・大文字にしない）: 区分 · 人 · 年 · 国。
  - 区分の語: 原種／未記載／Hybrid／Clone／個体／実生。
  - 人: 原種は記載者。ほかは「作出 X」、命名者しか記録が無ければ「命名 X」。
  - 国は原種と未記載だけ。
- **削るもの**: 「由来: 1件」（全行が 1）、信頼度のバー、人物・産地の台帳の「No.」列、一覧の交配式の行。
- **画面ごとの変え方**:
  - 新着は左に MM.DD を足す。
  - 人物ページでは人を省く。
  - 産地ページと「同じ産地」では国を省く。
  - 系統図の箱は名前と区分だけ。
- **不具合**: 新着・人物・産地の台帳は、describe() に _tags・_verifiedAt・_selectedFrom・_parents・_formulaStatus を渡していない（archive.js:440）。
  - そのため 'Fort Sherman' が「Clone・未収録」と出て、検証済の ✓ も出ない。
  - Hybrid の収録判定が、属一覧とずれる恐れがある。
  - 直し方: cultivarData の項目をそのまま渡す。
- **件数の見出し**: 属一覧の「0 品種が登録されています」（forms.js:2107）を「収録 n」に直す。表示した行数で数える。
