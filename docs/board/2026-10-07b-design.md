## 0. 要約（統括向け）

**第7回の決まりは、数字の上ではほぼ入っています。** 文字サイズは 12〜20 種から 5〜8 種に減りました（6 段とボタンの 15px）。12px 未満は投稿フォームの 4 個を除いて 0 です。mono の割合は 17〜75% から 3〜42% に下がりました。

**ただし、実機（タッチ端末）でだけ起きる崩れと、T69 で入った不具合が 1 件あります。告知（10/17）前に直すべきものは 4 件です。**

1. **antolakii のページが半分しか描かれない（T69 で発生）。**
   - 標本ラベル、関連する品種、前後の品種、一覧への出口、登録日の行が出ません。
   - 原因は、表示名（sp. "antolakii"）と保存名（antolakii）が違うと描画を止める判定です（`archive.js:1039`）。
   - 同じ「h1 の文字を品種名として使う」書き方が 9 箇所あります。この品種では「記録を追加」の送信が何もせずに終わり、投票と再調査依頼は違う名前で送られます。
2. **スマホで年表・関連・前後の行が崩れる。**
   - 年表で「metallicum 1860magnificum 1865」のように項目がくっつきます。
   - 関連では「Anthuriumsp. "queremalense"」と空白が消えます。
   - 前後の品種は「← 前の / 品種」が細い列に押し込まれます。
   - 原因はタッチ端末用の 44px 規則（`archive.css:1080`）が `display:inline-flex` を付けていることです。
3. **一覧の 2 行目が語の途中で折れる。** 「パ／ナマ」「コ／ロンビア」「フランス領ギ／アナ」のように折れます。属一覧の件数行も「·」で始まる行ができます。
4. **人物・産地・新着の一覧で写真のサムネイルが出ない。** crystallinum・warocqueanum・splendidum には写真がありますが、点線の空き枠が並びます。サムネイルの対応表を描画した時点で写し取っていて、あとから届いた分が反映されないためです。

このほか、読み込み中に画面が大きくずれます（CLS 0.42〜0.99。目安は 0.1 未満）。統一レイヤーの取りこぼしも十数件あります。

**新しい提案の柱は 3 つです。**
- 読み込み中も完成形と同じ骨組みを見せる（ずれ 0）
- 写真がないページでは記録を先に読ませる（写真なしの表示を小さく）
- 写真に図版キャプションを付ける

ダークモードは作りません。代わりに、端末の強制ダークで紙の色が反転しないよう 1 行で止めます。

## 2. 不具合（決まりから外れている所・崩れ・操作しづらさ）

### High

**D1　antolakii のページが途中で止まる（T69 で発生）**
- 画面: /anthurium/antolakii
- 症状: 標本ラベル（名前の状態・報告されている産地など）、関連する品種、前後の品種、「Anthurium の一覧 →」、登録日の行が出ない。記録の下に空の罫線が 2 本残るだけ。
- 原因: `archive.js:1039` の `renderDetail` が `h1.textContent.trim() !== displayName` のとき「別のページに移った」と見なして止まります。T69 で h1 が `Anthurium sp. "antolakii"`、保存名が `Anthurium antolakii` になり、両者が一致しなくなりました。
- 同じ書き方の箇所: `forms.js:163`（投票）、`:233`・`:1954`（記録を追加。該当データが見つからず、送信が何もせずに終わる）、`:390`（言語切替後の再描画）、`dialogs.js:161`・`:197`（削除依頼・画像の報告）、`archive.js:1305`・`:1314`（再調査依頼が違う名前で登録される）。
- 直し方:
  - `pages.js:1219` の h1 を描くところで `h1.dataset.key = displayName` を入れる。
  - 共通関数 `currentCultivarKey()`（`h1.dataset.key || h1.textContent.trim()`）を作り、上の 9 箇所をこれに置き換える。
- 今後も、表示名と保存名が違う品種（未記載種）を足すたびに同じことが起きます。

**D2　タッチ端末で年表・関連・前後の行が崩れる**
- 画面: トップの年表／品種ページの「同じ産地」と前後の品種（実機でだけ起きる）
- 原因: `archive.css:1080` の `@media (pointer: coarse) { .timeline__list a, .related a, … { display: inline-flex } }`
  - 年表は `display:block` が上書きされ、項目が横につながります。
  - inline-flex の中では `<i>Anthurium</i> sp.` の間の空白が消えます。
  - 前後の品種のリンクが横並びの flex になり、ラベルと名前が 2 列に割れます。
- 直し方: この行を、単独で置かれるリンク（`.related__exit a, .story__more, .record-add, .header__contribute, .header__lang, .breadcrumb a`）だけに絞ります。行の形をしたリンクには次を指定します。
  - `.timeline__decade a, .related__group li a`: `display:block; padding-block:10px`（44px を確保しつつ文字は通常の流れのまま）
  - `.related__nav a`: `display:flex; flex-direction:column; min-height:44px`
  - 年表の各項目の間には `.timeline__decade > div { display:flex; flex-wrap:wrap; column-gap:16px }` で間隔を取ります。

**D3　一覧の 2 行目と件数行が語の途中で折れる**
- 画面: 属一覧・トップの新着・人物・産地（`entryLine` を使う全一覧）、属一覧の件数行
- 例: 「原種 · Croat · 2005 · パ／ナマ」「Linden ex／Schott」「· 記録不足 1」が行頭に来る
- 直し方: `archive.js` の `entrySubHtml` で、各要素を `<span class="entry__seg">` で包みます。`.entry__seg { white-space: nowrap }` を付け、区切りの「 · 」は span の外に置きます。件数行（`forms.js` の件数文と `pages.js` のサーバー経路）にも同じ部品を使います。

**D4　人物・産地・新着でサムネイルが出ない**
- 画面: /people/croat/、/locality/colombia/（crystallinum・warocqueanum・splendidum など写真がある品種まで空き枠になる）
- 原因: `archive.js:962`・`:1013` が描画の時点で `_thumbMap` を写し取って渡しています。`pages.js` の `loadCultivarThumbnails()` は完了時に属一覧と今日の一葉しか描き直しません。
- 直し方: `renderEntriesLedger` の中で、引数に無い名前は `window._thumbMap` を直接引きます。`loadCultivarThumbnails` の `.then` で `_ledgerArgs` がある場合は描き直します。人物・産地に直接着地したときも `loadCultivarThumbnails()` を呼びます。

## 3. 新しい改善アイデア（AI っぽく見えない、編集的な方向は維持）

**I1　読み込み中も「完成した台紙と同じ骨組み」を見せる（D9 の解決）**
- 品種ページの静的スタブ（`scripts/generate-static-pages.js`）を、SPA と同じ順番・同じ部品で出力します。
  - 区分の印 → h1 → 標本ラベル `.specimen`（同じ dl）→ 操作行と同じ高さの空き行 → 図版
  - 引用行の mono と英語の国名をやめます。
  - 写真がある品種だけ図版の枠（4:5）を確保します。
- これで SPA に入れ替わってもずれず、検索エンジンが読む内容も画面と一致します。
- 属一覧・人物・産地は、データが届くまで h1 と 8 行の骨組みを出します。骨組みは 48px の点線枠と灰色の細い線 2 本で、写真なしの空き枠と同じ表現です。
- フッターと標準の文言は、index.html の初期値を translations.json の日本語にそろえます。
- 目標: 主要 5 画面で CLS 0.1 未満。

**I2　写真がないページは記録を先に読ませる**
- いまは写真なしのシート（約 170px）が記録の前に入り、375px では記録の本文が 2 画面目に落ちます。
- ≤640px で写真がないときは、シートを 1 行の点線の帯にします。高さ 56px、文言は「写真なし — 写真を追加」です。
- 部品は `.sheet--plate` のままで、行の形の版（`.sheet--inline`）を足します。
- hookeri・Dark Mama・antolakii では、記録の書き出しが 1 画面目に入ります。

**I3　写真に図版キャプションを付け、高さを抑える**
- 写真の下の 1 行を「図 1 · 栽培株 · 撮影 はれ · 2026.03.13」にします。番号・撮影者・日付は mono、それ以外はゴシックです。図鑑の図版の作法で、写真の出どころが自然に伝わります。
- 写真が 2 枚以上なら「図 1 / 3」と数字で示し、左右の矢印を減らします。
- ≤640px では写真の台紙を `max-height: 70svh` にします。warocqueanum の写真はいま約 610px あり、ラベル → 写真 → 記録の見出しが 1.5 画面に収まるようにします。
- 写真を押すと全画面で開き、背景は紙の色にします（黒いライトボックスにしない）。

**I4　新着を「日付の見出し + 行」にまとめる（第7回の決定の一部変更。ボードの裁定が必要）**
- いまは「2026.10.03」が 8 行すべての先頭に付き、トップの mono が 42% になっています。
- 「2026.10.03 — 8 品種」を小見出し（ラベル）にし、各行の日付を外します。現場の記録帳の作法になります。
- mono は 35% 以下に下がり、トップの高さは約 60px 短くなります。

**I5　前後の品種に一覧の中での位置を出す（D8 と一緒に）**
